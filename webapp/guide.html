安装引导

先去演示页体验 →

同一个渲染引擎，提供三种安装方式。电脑推荐 方式一；手机/平板推荐 方式二；不想装任何东西就用 方式三。

方式一 · 浏览器扩展（电脑 Chrome / Edge）

  1. 打开扩展管理页：地址栏输入 chrome://extensions（Edge 为 edge://extensions）
  2. 打开右上角（Edge 为左侧）的 开发者模式
  3. 点 加载已解压的扩展程序，选择本工具的 extension 文件夹
  4. 固定到工具栏。在任意网页选中公式代码 → 点浮出的 ∑ 渲染

快捷键 Alt+R 渲染当前选区；扩展弹窗里还有「渲染台」入口。

方式二 · 用户脚本（手机 / 平板，含安卓 Chromium 内核浏览器）

安卓：Kiwi / Via / Edge Canary + Tampermonkey（或浏览器自带脚本功能）

  1. 安装支持用户脚本的浏览器（Kiwi Browser、Via、X Browser 等）
  2. Kiwi：在 Chrome 应用商店装 Tampermonkey；Via：自带「脚本」功能，无需安装
  3. 打开 Tampermonkey → 管理面板 → ＋ 新建脚本 → 全选删除 → 粘贴 userscript/formula-render.user.js 的全部内容 → Ctrl+S 保存（Via：粘贴到脚本编辑器保存即可）
  4. 打开任意网页，选中公式代码 → 点 ∑ 渲染
怎样把 userscript 文件内容弄到手机上粘贴？
  • 电脑上用微信/QQ 把 formula-render.user.js 发到手机，用文本打开全选复制；
  • 或把整个文件夹同步到手机（网盘/数据线），用浏览器打开该文件地址后复制。

iPad / iPhone：Safari + Userscripts App（需 iOS15+）

  1. App Store 安装免费开源的 Userscripts 应用，按其引导开启 Safari 扩展
  2. 把 formula-render.user.js 导入该应用（支持文件导入）
  3. 选中公式代码 → 点 ∑ 渲染

方式三 · 书签脚本 Bookmarklet（任何浏览器，零安装）

电脑：把下面这个按钮拖到浏览器的书签栏即可：

∑ 渲染公式（拖到书签栏）

手机/平板：先任意收藏一个页面 → 编辑该书签 → 把网址替换为文件 bookmarklet/formula-render.bookmarklet.txt 里的全部内容（javascript: 开头）→ 在看公式的页面点这个书签。注意：点一次开启，再点一次打开渲染面板；书签脚本需联网加载渲染引擎。

部分浏览器（如 Chrome 桌面版）粘贴 javascript: 书签时会自动删掉前缀，粘贴后手动补上 javascript: 即可。

方式四 · 独立渲染台（无需安装，可离线）

直接双击打开 webapp/console.html（或由扩展弹窗进入）。把 AI 输出的整段文字粘进去，点「渲染」，可复制为富文本公式（粘进 Word 保留公式外观）或 MathML。

常见问题

  • 点了渲染没反应？扩展对浏览器自带页面（chrome://、商店页等）不生效，属浏览器安全限制；换普通网页测试。
  • 没弹出 ∑ 按钮？选区里没有可识别的公式（纯文本、普通代码不会打扰你）。也可以选中后按 Alt+R 或用扩展弹窗的「渲染当前选区」。
  • 公式显示不完整/报错？个别写法 KaTeX 不支持，报错信息会显示在卡片里，原代码会以灰色保留，不会丢失。
  • 隐私？扩展、用户脚本、渲染台全部本地运行，不上传任何内容；仅书签脚本需联网加载一次 KaTeX 引擎。
